# AI development-session exports

`development/` contains authentic Codex CLI session exports from this QuickDrop
workspace, exported on 29 October 2026. Each JSONL retains the original session
metadata and chronological raw user/assistant message records. No reconstructed or
synthetic exchanges were added. Tool payloads, hidden reasoning and telemetry were
excluded from these conversation exports. Credentials present in local environment
files and recognizable access tokens/connection strings were redacted.

See `development/provenance.json` for original source locations, source/export hashes,
record counts, scope and redaction counts. Original local session files are unchanged.
These are actual development conversations, distinct from runtime model evaluations.

`final-audit/` preserves the original live-agent audit evidence unchanged.
`final-remediation/` contains the subsequent real Nova regression evidence.
